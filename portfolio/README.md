# Wensh — Portfolio

Personal landing page for Mostafa Nasser (Wensh). Built with React, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build to dist/
```

- Sections: `src/sections/` (Hero, Marquee, About, Services, Projects)
- Reusable pieces: `src/components/` (FadeIn, Magnet, AnimatedText, ContactButton, LiveProjectButton)
- Contact email: `src/data.ts`
- Hero photo: `public/wensh.jpg`
- Project images: placeholders in `src/sections/ProjectsSection.tsx`; replace with real screenshots.
