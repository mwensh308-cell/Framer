# بوت إشعارات الهاتف

يجمع كل إشعارات هاتف Android في مكان واحد. يحفظها في قاعدة بيانات SQLite مع بحث نصي كامل، ويرسل كل
إشعار إليك في تيليجرام.

```
هاتف Android                     الخادم (هذا المجلد)                    تيليجرام
┌──────────────────┐  POST JSON  ┌───────────────────────────┐  sendMessage  ┌────────┐
│ جسر الإشعارات     │ ──────────▶ │ /api/notifications         │ ────────────▶ │ أنت    │
│ NotificationList- │  + الرمز    │ SQLite + FTS5 (بحث)         │ ◀──────────── │ /search│
│ enerService       │             │ بوت: /last /search /export │   أوامر       └────────┘
└──────────────────┘             └───────────────────────────┘
```

> **iPhone:** نظام iOS لا يسمح لأي تطبيق بقراءة إشعارات التطبيقات الأخرى، لذلك هذا الحل لهواتف Android فقط.

## 1) تشغيل الخادم والبوت

```bash
cd notify-bot
cp .env.example .env
```

املأ في `.env`:
- `TELEGRAM_BOT_TOKEN`: رمز البوت من @BotFather.
- `OWNERS`: رقمك في تيليجرام. أرسل `/id` للبوت لتعرفه.
- `DEVICE_TOKEN`: سرّ لا يقل عن 16 حرفًا. يمكنك توليده بهذا الأمر:

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

ثم شغّل الخادم:

```bash
npm start
```

يحتاج Node 22.13 أو أحدث، لأنه يستخدم `node:sqlite` المدمج. لا توجد أي مكتبات خارجية.

**يجب أن يصل الهاتف إلى الخادم بإحدى هذه الطرق:**
- **على شبكة البيت نفسها:** `http://<IP الكمبيوتر>:8787`.
- **من أي مكان:** شغّله على خادم VPS خلف HTTPS، مثل Caddy أو Nginx، أو عبر نفق مثل Cloudflare Tunnel، واستخدم عنوان `https://…`.

## 2) تطبيق Android

الكود في `android/`. بدون مكتبات خارجية، ويعمل على Android 7 فما فوق.

**طرق البناء:**
- **من GitHub:** يُبنى الـ APK تلقائيًا عبر workflow ‏`notify-bot`. نزّله من صفحة Actions → آخر تشغيل → Artifacts → `notify-bridge-apk`.
- **محليًا:** تحتاج Android SDK وJDK 17. افتح المجلد `android/` في Android Studio، أو نفّذ `gradle assembleDebug`.

**الإعداد على الهاتف:**
1. ثبّت الـ APK. قد تحتاج تفعيل "التثبيت من مصادر غير معروفة".
2. اضغط **منح إذن قراءة الإشعارات** وفعّل "جسر الإشعارات".
3. أدخل عنوان الخادم و`DEVICE_TOKEN`، ثم اضغط **حفظ**.
4. اضغط **إرسال إشعار تجريبي**. يجب أن تصلك رسالة في تيليجرام.
5. اختياري: اسمح للتطبيق بالعمل دون قيود البطارية من إعدادات التطبيق، حتى لا يوقفه النظام.

**ما يفعله التطبيق:**
- يرسل عنوان الإشعار ونصه واسم التطبيق والوقت.
- يتجاهل ملخصات المجموعات، ويتجاهل الإشعارات الدائمة (موسيقى، تنزيلات) إلا إذا فعّلتها.
- إذا انقطع الاتصال، يحفظ الإشعارات في طابور (حتى 2000 إشعار) ويرسلها دفعة واحدة عند عودة الاتصال.
- يمكنك استثناء تطبيقات بأسماء حزمها، مثل `com.mybank.app`.

> Android 15 يُخفي محتوى بعض الإشعارات الحساسة (مثل رموز التحقق) عن التطبيقات التي تقرأ الإشعارات.

## أوامر البوت

| الأمر | ماذا يفعل |
|---|---|
| `/last [عدد] [تطبيق]` | آخر الإشعارات، مثل `/last 20 whatsapp` |
| `/search <كلمات>` | بحث في كل ما حُفظ (عربي وإنجليزي، والكلمات تطابق من بدايتها) |
| `/today` · `/apps` | العدد حسب التطبيق: اليوم، وآخر 7 أيام |
| `/mute <تطبيق>` · `/unmute` · `/muted` | إيقاف إرسال تطبيق معيّن، مع استمرار حفظ إشعاراته |
| `/pause` · `/resume` | إيقاف الإرسال كله أو استئنافه، مع استمرار الحفظ |
| `/export [أيام]` | ملف CSV يفتح في Excel مع دعم العربية |
| `/stats` · `/id` | إحصاءات، ورقمك في تيليجرام |

## الخصوصية والأمان

الإشعارات تحتوي رسائل خاصة، ورموز تحقق، وبيانات بنكية. لذلك:
- الخادم يرفض أي إرسال لا يحمل `DEVICE_TOKEN`، ويقارن الرمز بطريقة آمنة من هجمات التوقيت.
- البوت لا يجيب إلا أصحاب الأرقام في `OWNERS`، وفي محادثة خاصة فقط، لا في المجموعات.
- البيانات محفوظة في ملف واحد على جهازك: `data/notifications.db`. ضع `KEEP_DAYS` لحذف القديم تلقائيًا.
- إذا كان الخادم خارج شبكة البيت فاستخدم HTTPS، ولا تشارك `DEVICE_TOKEN` مع أحد.
- كل إشعار يُرسل يمرّ عبر خوادم تيليجرام. لتطبيقات حساسة استخدم `/mute`، فتُحفظ إشعاراتها عندك ولا تُرسل، أو استثنها من التطبيق نفسه فلا تغادر الهاتف أصلًا.

## واجهة الخادم

`POST /api/notifications` مع الترويسة `Authorization: Bearer <DEVICE_TOKEN>`. الجسم يكون إشعارًا واحدًا، أو `{"items": [...]}` لعدة إشعارات:

```json
{ "device": "Pixel 8", "package": "com.whatsapp", "app": "WhatsApp", "title": "سارة",
  "text": "نلتقي الساعة 6؟", "subText": "", "category": "msg", "key": "0|com.whatsapp|1|…", "postedAt": 1763682240000 }
```

الرد: `{"stored": 1, "skipped": 0}`.
- الإشعار المكرَّر خلال دقيقتين يُتخطّى، لأن Android يعيد نشر الإشعار عند تحديثه.
- أي برنامج أتمتة يستطيع إرسال HTTP POST، مثل Tasker أو MacroDroid، يمكنه استخدام هذه الواجهة بدل التطبيق.
